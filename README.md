# 🐍 Python File & Folder Management

A small Python practice project built to test my logic-building skills and understanding of **File Handling in Python**.

This exercise allows users to perform different operations on files and folders through Python. I built it as a hands-on experiment to understand how Python interacts with the file system.

> This is a learning exercise, not a full-fledged production project.

## 🎯 Project Objective

The main objective was to apply Python concepts practically instead of limiting my learning to coding questions.

Through this exercise, I explored file and folder management, logical conditions, functions, and file system operations.

## ✨ Features

### 📁 Folder Operations
- Create new folders
- Read and display folder contents
- Rename existing folders
- Delete folders
- Check whether a folder already exists

### 📄 File Operations
- Create new files
- Read file contents
- Update file contents
- Rename files
- Delete files
- Check whether a file exists

## 🛠️ Technologies & Concepts Used

| Technology | Purpose |
|---|---|
| Python | Core programming language |
| `pathlib` | Working with file and folder paths |
| `os` | File system operations |
| Functions | Organizing different operations |
| Conditional Statements | Handling different situations |
| Loops | Iterating through data |
| File Handling | Creating, reading, updating, and deleting files |
